# SpendSmart – Personal Expense Tracker

SpendSmart is an Android personal expense tracker built using React Native and Expo.

## Features

* Add, edit, and delete expenses.
* Organize expenses by category.
* View monthly expense summaries.
* Visualize spending through charts.
* Store expense data locally on the device.

## Technologies Used

* React Native
* Expo
* JavaScript
* React Navigation
* AsyncStorage

[Download SpendSmart APK](../../releases/latest)

## Installation

1. Download the APK to your Android phone.
2. Open the downloaded file.
3. Allow installation from that source if Android asks.
4. Install and open SpendSmart.

**Note:** This is an Android application. Expense data is stored locally on each device and is not automatically synchronized between users.
